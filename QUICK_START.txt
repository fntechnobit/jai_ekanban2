QUICK DEPLOYMENT STEPS:
=======================

1. BACKUP FIRST! (Database and Files)
   mysqldump -u [user] -p [database] > backup.sql

2. Put application in maintenance mode:
   php artisan down

3. Extract this package to temporary location

4. Copy files to your application directory:
   cp -r deployment_package/* /path/to/application/

5. Delete obsolete files (see FILES_TO_DELETE.txt)

6. Set correct permissions:
   chmod -R 775 storage bootstrap/cache

7. Update dependencies:
   composer install --no-dev --optimize-autoloader

8. Run migrations:
   php artisan migrate

9. Clear and rebuild cache:
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache

10. Bring application online:
    php artisan up
