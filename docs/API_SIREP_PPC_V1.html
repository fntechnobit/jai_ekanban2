2. Autentikasi

Seluruh endpoint memerlukan token service-to-service pada header Authorization. Token mewakili aplikasi, bukan pengguna, dan diterbitkan terpisah untuk setiap konsumen (EK dan FK) agar dapat dicabut atau dirotasi sendiri-sendiri.

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
KondisiHTTPKode error
Header tidak dikirim401UNAUTHENTICATED
Token tidak valid / kedaluwarsa401UNAUTHENTICATED
Token valid tetapi tidak berhak403FORBIDDEN

3. Konvensi Umum

3.1 Format respons daftar

Seluruh endpoint daftar memakai amplop yang sama:

Field metaTipeKeterangan

per_pageintegerJumlah baris per halaman yang berlaku

Urutan bersifat tetap dan tidak dapat diubah lewat parameter:

13. Kontrak & Batasan Data

Ketentuan berikut adalah bagian dari kontrak API dan berlaku pada setiap respons.

NoKetentuanRincian
1id_listing stabil Satu baris demand memiliki satu id_listing selamanya, termasuk setelah direvisi. Nilai tidak pernah null dan tidak pernah didaur ulang untuk baris lain.
2Urutan deterministik /listing selalu terurut id_listing menaik, konsisten lintas halaman.
3Keunikan seq seq unik dalam kombinasi (date, conveyor_code, assycode). Konsumen memakai kombinasi ini sebagai kunci deduplikasi.
4Integritas referensi Setiap conveyor_code pada /listing ada di /conveyors; setiap assy ada di /assy.
5Penanda perubahan Setiap perubahan nilai pada baris — termasuk perubahan status — menaikkan revision dan memperbarui updated_at.
6Pembatalan tanpa penghapusan Baris yang dibatalkan tetap dikembalikan dengan status: "cancelled", tidak dihapus dari API.
7Kelengkapan rentang Permintaan date_from=A&date_to=B mencakup seluruh baris A ≤ date ≤ B. meta.total selalu menunjukkan jumlah sebenarnya.
8Batas panjang field conveyor_code ≤ 25 karakter · assycode ≤ 20 · assy ≤ 100. Nilai sudah ter-trim, tanpa spasi ganda.
9Himpunan karakter Field kunci (conveyor_code, assycode, assy) memakai ASCII. Salah satu konsumen masih beroperasi dengan charset latin1.
10Zona waktu tunggal date berupa tanggal murni; seluruh timestamp ISO-8601 dengan offset +07:00.
